# Jake pet art

This is the original exported **v2** animated pet sprite sheet for Jake. The versioned transparent PNG can be downloaded directly as [jake-pet-v2.png](https://raw.githubusercontent.com/lucidIT-LLC/o-matic-firm/main/firm/assets/pets/jake/v2/jake-pet-v2.png). Metadata is in [`metadata.json`](metadata.json).

## Install in Codex desktop

After this change is merged, open the [Install Jake pet](<codex://pets/install?name=Jake&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2FlucidIT-LLC%2Fo-matic-firm%2Fmain%2Ffirm%2Fassets%2Fpets%2Fjake%2Fv2%2Fjake-pet-v2.png&description=Jake%2C+the+curious+o-MATIC+AI+surfer-professor+robot+coach.&spriteVersionNumber=2>) link. It opens Codex's pet install flow and passes the public sprite URL with `spriteVersionNumber=2`. The plugin marketplace install and pet install are separate steps; installing this plugin does not select or activate the pet.

The pet is artwork only. It does not change Jake's skill, identity, or behavior, and it does not provide live factory telemetry. Custom pets are stored locally and do not automatically sync to ChatGPT web. The web upload flow currently documents a different 1536 × 1872 sheet size, so this v2 atlas is intended for Codex desktop and compatible Codex CLI use.

See [Codex pet install links](https://learn.chatgpt.com/docs/reference/commands#pets) and [ChatGPT Pets](https://learn.chatgpt.com/docs/pets) for current host support.
